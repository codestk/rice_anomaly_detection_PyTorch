## Critical First Step - Read HISTORY.md

**BEFORE starting any work, ALWAYS read `HISTORY.md`** to understand:

- What changes have been made recently
- Current issues and their resolutions
- Ongoing tasks and their status
- Important notes about the codebase

Run: Get-Content HISTORY.md or read the file using the Read tool.

After completing any significant work:

1. Update HISTORY.md with:
   - Date and description of changes
   - Files modified
   - Any issues encountered and solutions
   - Pending tasks or follow-ups

This ensures future AI sessions understand the project context.
